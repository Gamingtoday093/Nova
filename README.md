Game Engine/Game *(Car/Carpet)* project for learning DX11, Graphics Rendering and Creating a RTS Game. The original version of this project is [Abaddon](https://github.com/Gamingtoday093/Abaddon) but now rewritten to be all made by me.

## How to setup Nova
1. Clone the project
2. Run Project/**CreateProjectFiles-vs2022.bat" to generate the solution

## How to build & run Nova
1. Setup the project
2. Open and compile the generated solution
3. Find the Output **Nova.exe** under bin/{build-config}/
